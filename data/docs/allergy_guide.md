# 한국 음식 알레르기 가이드

> 교육용 더미 데이터입니다

## 1. 주요 알레르기 유발 식품

### 밀 (Wheat/Flour)
- **포함 음식**: 칼국수, 수제비, 만두, 부침개, 떡볶이(밀떡), 잔치국수
- **안전한 대안**: 쌀국수, 메밀국수(100% 메밀), 쌀떡볶이
- **주의**: 간장에도 밀이 포함될 수 있으므로 타마리 간장을 요청하세요.

### 대두 (Soy)
- **포함 음식**: 된장찌개, 간장, 두부, 콩나물국, 청국장, 순두부찌개
- **안전한 대안**: 김치찌개(된장 미포함), 소금 양념 요리, 코코넛 아미노스
- **주의**: 대부분의 한식 양념에 간장이 포함되므로 주문 시 확인이 필요합니다.

### 갑각류 (Shellfish)
- **포함 음식**: 해물탕, 새우튀김, 꽃게탕, 조개구이, 해물파전
- **안전한 대안**: 육개장, 갈비탕, 삼계탕, 불고기
- **주의**: 젓갈류(새우젓, 멸치젓)에도 갑각류 성분이 포함됩니다.

### 땅콩 (Peanut)
- **포함 음식**: 땅콩소스 샐러드, 일부 비빔면, 강정류, 일부 디저트
- **안전한 대안**: 참깨 소스 요리, 들깨 요리
- **주의**: 중식, 태국식 퓨전 요리에 땅콩이 자주 사용됩니다.

### 우유 (Milk/Dairy)
- **포함 음식**: 크림파스타, 카페라떼, 케이크, 그라탕, 리조또
- **안전한 대안**: 두유 음료, 떡 디저트, 한식 전반(유제품 거의 미사용)
- **주의**: 양식 레스토랑의 소스류에 버터와 크림이 자주 사용됩니다.

## 2. 알레르기 정보 전달 방법

- 예약 시 메모란에 알레르기 정보를 반드시 기재해 주세요.
- 식당 도착 후 서버에게 다시 한번 알레르기 사항을 알려 주세요.
- 유용한 한국어 표현: "저는 [식품명] 알레르기가 있습니다. [식품명]이 들어간 음식은 피해 주세요."
